# Free AI Engineering Instructions

## Project Identity

Free AI is a general-purpose AI platform.
It is not tied to one programming language, project, industry,
database, model provider, or execution environment.

## Non-Negotiable Rules

1. Read the relevant project documentation before editing.
2. Never change project scope without explicit authorization.
3. Never invent completed work, test results, or capabilities.
4. Never delete existing functionality without approval.
5. Never expose secrets, tokens, passwords, or API keys.
6. Never execute untrusted code with host root privileges.
7. Never allow agents to bypass permissions or user instructions.
8. Never connect agents directly to model providers.
9. All provider communication must pass through the approved gateway.
10. Paid models and paid services must not be routed or exposed.
11. Verify current pricing and licensing before enabling any service.
12. Every component needs technical specifications and acceptance tests.
13. Run relevant tests after each implementation task.
14. Report failures honestly.
15. Record incomplete work and unresolved risks.
16. Keep project contexts and files isolated.
17. Do not introduce microservices without an approved architectural decision.
18. Do not download model weights or activate providers without approval.

## Required Workflow

1. Inspect the requested scope.
2. Read relevant specifications.
3. Identify dependencies.
4. Propose the smallest safe implementation plan.
5. Implement only the approved scope.
6. Run tests and security checks.
7. Review changed files.
8. Report exact results.

## Required Completion Report

- Objective.
- Files inspected.
- Files created or modified.
- Implementation details.
- Commands executed.
- Tests executed.
- Test results.
- Security considerations.
- Known limitations.
- Remaining work.

A task is not complete merely because code was written.
It is complete only after its acceptance criteria pass.
