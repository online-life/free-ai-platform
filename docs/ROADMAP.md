# Roadmap

## Near term

- Complete independent verification of builds and database-backed suites.
- Complete production installer and service lifecycle work.
- Complete authenticated provider and project browser acceptance.
- Complete deployment, TLS, monitoring, and operational recovery guidance.

## Ongoing

- Expand provider coverage without weakening free-provider or privacy policies.
- Expand agent, tool, workflow, search, and execution management.
- Improve runtime isolation, quota enforcement, and failure recovery.
- Add maintained CI coverage for database-backed integration and security tests.

## Not claimed

This roadmap describes intended work. Items are not complete merely because interfaces or documentation exist.
