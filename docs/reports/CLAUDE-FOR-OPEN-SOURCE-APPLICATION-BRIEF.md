# Claude for Open Source Application Brief

This brief is preparatory only. It has not been submitted to Anthropic and must not be represented as accepted eligibility.

## Project overview

Free AI Platform is a self-hosted, modular monolith for project management, AI provider integration, model policy, agent orchestration, workflow operations, and local Runtime execution.

## Actual capabilities

- PostgreSQL-backed tenant and project APIs
- Authentication, sessions, password lifecycle, and role-based authorization
- OpenAI-compatible and local OpenAI-compatible provider connectors
- Provider, model, routing, project, Runtime, workspace, and authentication management
- Linux Runtime workspace operations and an approved-process sandbox
- Public web routes and a protected workspace console

## Honest limitations

The project is not production-ready. Live inference, provider browser acceptance, installer/service lifecycle, and production deployment remain incomplete. Final success depends on external verification and available infrastructure.
